# Visa Helper AI

## The Problem

Navigating international visa requirements is notoriously stressful. Official government immigration portals present dense legal prose scattered across fragmented pages. Applicants frequently misinterpret requirements, upload incorrect document formats, or miss mandatory steps, leading to costly application rejections and delays.

---

## What I Built

I created **Visa Helper AI**, a web application built with Python, Streamlit, and custom HTML/CSS styling. It functions as an intelligent conversational assistant that translates complex visa policies into clear, dynamic document checklists, step-by-step application timelines, and personalized document preparation guides.

---

## My Decisions

- **Retrieval-Augmented Guidance**: Structured context prompts using official visa policy documents to prevent model hallucinations.
- **Pastel UI & Theme Toggle**: Designed a calming pastel interface with user-friendly typography and light/dark theme toggling to reduce applicant stress.
- **Dynamic Checklists**: Generated interactive HTML document checklists that users can track in real-time as they assemble application files.

---

## How AI Helped

- **Summarization Prompts**: Engineered prompts that transform complex 50-page immigration PDF manuals into 5 bullet-point action checklists.
- **Natural Language Understanding**: Mapped user intent (e.g. "I am a student applying for a UK visa from India") directly to target requirement checklists.
