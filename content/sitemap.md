# Information Architecture & Sitemap

## Site Structure Map

```
Portfolio Root (index.html)
│
├── Navigation Header
│   ├── About (Tab 1)
│   ├── AI Projects (Tab 2)
│   ├── Writing (Tab 3)
│   ├── Journey (Tab 4)
│   └── Contact (Tab 5)
│
├── Global Interactive Search Palette (Ctrl+K / Cmd+K)
│
├── Main Viewport Sections
│   ├── About Section: Headline, Bio, Proof Statement, Positioning Cards
│   ├── Projects Grid: Case study cards with live demo links, GitHub links, detail modal triggers
│   ├── Writing Grid: Books, published poems, ISBN details, zoomable cover previews
│   ├── Journey Section: FlyRank Internship, Education (Medi-Caps B.Tech CSBS), Writing awards
│   └── Contact Section: Direct email, LinkedIn, GitHub, functional contact form
│
├── Dynamic Modals
│   ├── Project Detail Modal (Hero banner, overview, problem/solution, markdown case study, screenshot gallery)
│   └── Lightbox Image Zoom Modal
│
└── Footer
    ├── FlyRank AI Intern & Graduate Badge
    ├── Technology Stack Disclaimer
    └── Copyright & Contact Info
```
