# Known Visual Limitations & "Still Ugly" List

Before final visual polish, the following components are functionally complete but visually plain by design:

1. **Bare Form Input Controls**: Contact form fields use clean Zinc borders (`border-zinc-800`) without heavy glowing gradients.
2. **Standard Modal Scrollbar**: Project detail modal uses native thin scrollbars (`scrollbar-thin`) to preserve fast scrolling performance.
3. **Restrained Text Typography**: Typography relies exclusively on Inter regular and bold weights to keep content readable without heavy decorative elements.
